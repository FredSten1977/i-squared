Belastningstest

Sender mange stemmer mot den ekte databasen i Supabase (adressen i config.js), slik som når salen stemmer samtidig, og måler hvor mange som kommer fram og hvor lang tid det tar.

  1. Åpne en avstemning på kontrollflaten (f.eks. «Åpne før-avstemning» på påstand 1).
  2. Velg antall stemmer og hvor raskt de skal komme, og trykk Start.
  3. Etterpå: ADMIN → Nullstill hele arrangementet (teststemmene er vanlige stemmer).
